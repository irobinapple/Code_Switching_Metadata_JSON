========================================================
  Ace - CSMJ Tool  —  How to run (no tech skills needed)
========================================================

WHAT YOU HAVE
  A folder called "Code_Switching_Metadata_JSON".
  Keep the whole folder together — do not move files out of it.

------------------------------------------------
WINDOWS  (most people)
------------------------------------------------
  1. Open the folder.
  2. Double-click the file named:   Ace-CSMJ.bat
  3. A black window opens. The FIRST time, it sets things up and
     may take a couple of minutes — this is normal. Just wait.
  4. Your web browser opens automatically at:
        http://localhost:8501
     That is the tool. Start working there.

  TO STOP:  close the black window.
  TO START AGAIN LATER:  double-click Ace-CSMJ.bat again
                         (it will be quick from now on).

  WANT A DESKTOP ICON?  double-click  CreateDesktopShortcut.bat  once.
     You then get an "Ace - CSMJ" icon on your Desktop to start it.

  UPDATES:  the tool updates itself automatically each time you open it
     (if it was set up with Get-Ace-CSMJ.bat). Nothing for you to do.

  If Windows shows a blue "Windows protected your PC" box:
     click "More info"  ->  "Run anyway".
     (This just means the file came from the internet.)

------------------------------------------------
MAC
------------------------------------------------
  1. Open the folder (or, for a first-time install, double-click
     Get-Ace-CSMJ.command to download the tool).
  2. Double-click:   Ace-CSMJ.command

     FIRST TIME ONLY - macOS blocks files from the internet:
       If you see "cannot be opened because it is from an
       unidentified developer", do this instead:
         right-click (or Control-click) the file
           -> Open
           -> Open  (in the box that appears)
       You only ever have to do this once per file.

     If macOS offers to install "Command Line Developer Tools",
     click Install and wait, then double-click the file again.

  3. A Terminal window opens and sets things up. The FIRST run
     takes a couple of minutes - this is normal. Just wait.
  4. Your browser opens automatically at:
        http://localhost:8501
     That is the tool. Start working there.

  TO STOP:  close the Terminal window.
  TO START AGAIN LATER:  double-click Ace-CSMJ.command
                         (quick from now on, and it auto-updates).

  WANT IT IN YOUR DOCK?  drag Ace-CSMJ.command onto the Dock,
     then click it any time to start the tool.

------------------------------------------------
NEED HELP?
------------------------------------------------
  Send a photo/screenshot of the black window (or Terminal) to
  whoever set this up for you. That shows exactly what went wrong.
